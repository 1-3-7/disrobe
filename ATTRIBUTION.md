# Crediting Disrobe

This guide implements Section 6 of the Disrobe Source-Available License, Version 1.1. The License controls if this guide and the License differ.

## Required credit

Every Publication arising from use of Disrobe or its Output must contain this exact line:

```text
This work used Disrobe, created by 1-3-7: https://github.com/1-3-7/disrobe
```

The requirement applies to every user and every license category: personal projects, independent research, academic work, nonprofit research, journalism, and commercial use under a paid license. It applies to public, internal, confidential, and client-facing work, and to work that contains no Disrobe code but relies on Output, including translated, summarized, reformatted, or agent-generated material.

Include the credit by the first time the work is circulated, submitted, delivered, or presented to anyone else, and keep it in later versions. Private working notes that are never shared do not need it until they are shared.

The credit identifies the creator of the tool. It does not make 1-3-7 a coauthor, analyst, expert, sponsor, or endorser of your work, and you must not describe it that way. A generic list of tools, a site-wide terms page, a buried code comment, or a link without the creator's name does not satisfy the requirement.

## Copy-ready formats

### Plain text

```text
This work used Disrobe, created by 1-3-7: https://github.com/1-3-7/disrobe
```

### Markdown

```markdown
This work used Disrobe, created by 1-3-7: <https://github.com/1-3-7/disrobe>
```

### HTML

```html
<p>This work used Disrobe, created by 1-3-7: <a href="https://github.com/1-3-7/disrobe">https://github.com/1-3-7/disrobe</a></p>
```

### BibTeX

```bibtex
@misc{disrobe,
  author = {{1-3-7}},
  title = {Disrobe},
  howpublished = {Software},
  url = {https://github.com/1-3-7/disrobe}
}
```

A bibliography entry supplements the exact credit line; it does not replace it.

### Research methods or report footnote

```text
This work used Disrobe, created by 1-3-7: https://github.com/1-3-7/disrobe
Responsibility for the analysis, validation, interpretation, and conclusions remains with the authors of this work.
```

### Advisory or vulnerability disclosure

```text
Tools: This work used Disrobe, created by 1-3-7: https://github.com/1-3-7/disrobe
```

If a CVE form or advisory field cannot hold the line, put it in the supporting advisory or source document linked from the submission and ask for it to be included.

### Court, expert, or regulatory filing

```text
Tool attribution: This work used Disrobe, created by 1-3-7: https://github.com/1-3-7/disrobe
The creator of the tool did not perform, review, or endorse this analysis.
```

Place it in the methodology, declaration, report, or a permitted footnote or exhibit. Never alter original evidence to add it.

### Journalism

```text
Reporting tools: This work used Disrobe, created by 1-3-7: https://github.com/1-3-7/disrobe
```

Use an article tools credit, source note, or contextual credit note. Free journalism use is limited to Bona Fide Journalism under License Section 5; sponsored content, vendor research, paid intelligence products, and client work are Commercial Use.

### Client deliverables and commercial work

```text
Analysis tool credit: This work used Disrobe, created by 1-3-7: https://github.com/1-3-7/disrobe
```

Include it in the methods or tools section of the deliverable or a credit note delivered with it. A paid commercial license does not remove this requirement unless the signed agreement expressly waives License Section 6. Client confidentiality preferences do not remove it.

### Slides, talks, video, courses, and podcasts

```text
Analysis tool: This work used Disrobe, created by 1-3-7: https://github.com/1-3-7/disrobe
```

Put the line on a relevant slide or on-screen credit and in accompanying notes. For audio-only work, say that the work used Disrobe, created by 1-3-7, and direct listeners to the written credit in the episode notes.

### Datasets, exports, and excerpts

Put the line in a credit field, recipient-visible metadata, a cover note, or an `ATTRIBUTION` file delivered with the data.

## Legal restrictions

If a statute, court order, protective order, sealing rule, nonwaivable professional duty, or mandatory filing rule prohibits the credit in a particular place or at a particular time, use a lawful alternative location or defer the credit only as long as the restriction requires, then add it. Client preference, editorial preference, and voluntary confidentiality agreements are not legal restrictions. Never disclose protected information to satisfy the credit requirement.

## Mistakes

A first inadvertent omission can be cured once by correcting it completely within 30 days after you discover it or receive notice. Deliberate omission or removal is a material breach that terminates your license.
