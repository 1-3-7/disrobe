# Container, archive, firmware, and encrypted-volume extraction

- id: `binfmt-extract`
- ecosystem: binfmt
- claim: disrobe detects 103 container, archive, firmware, and encrypted-volume formats. 102 carry a generic in-tree payload extractor and LUKS1 carries a bounded raw-volume-key route plus a typed keyless wall. 42 generic routes are driven to member bytes on disk by an input this repository commits; the committed DMG input reaches detection only; 59 generic routes have no committed input. LUKS1 is graded separately against tracked plaintext.

- oracle strength: coverage-self-reported
- CI-attested: yes [CI]
- evidence basis: the delivered count is disrobe extracting from its own committed corpus and counting the generic formats that wrote bytes, not an independent check. The committed DMG input reaches detection only. The LUKS1 route is separately compared with tracked plaintext and an independently generated encrypted fixture. Individual format tests may use external byte manifests, but the 59 generic formats with no committed input carry no measurement at all
