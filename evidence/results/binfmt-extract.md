# Container, archive, firmware, and encrypted-volume extraction

- id: `binfmt-extract`
- ecosystem: binfmt
- claim: disrobe detects 103 container, archive, firmware, and encrypted-volume formats. 102 carry a generic in-tree payload extractor and LUKS1 carries a bounded raw-volume-key route plus a typed keyless wall. 28 generic routes write member bytes from an input this repository commits that bsdtar 3.8.8, 7-Zip 26.02 or the format's own decompressor confirms; 13 more extract from a committed input that no installed reference tool confirms; the committed DMG and PAR2 inputs reach detection only; 59 generic routes have no committed input. LUKS1 is graded separately against tracked plaintext.
- measured: 28 extracted from a committed input / 103 detected
- oracle strength: coverage-self-reported
- CI-attested: yes [CI]
- evidence basis: the delivered count is the generic formats whose member bytes, extracted from a committed input, match bsdtar 3.8.8, 7-Zip 26.02 or the format's own decompressor; the 13 extractions no installed reference tool confirms are not counted. The committed DMG and PAR2 inputs reach detection only. The LUKS1 route is separately compared with tracked plaintext and an independently generated encrypted fixture. Individual format tests may use external byte manifests, but the 59 generic formats with no committed input carry no measurement at all
- reproduce: `cargo test -p disrobe-binfmt published_container_counts_match_this_enum`
- gate source: ContainerKind::ALL in crates/disrobe-binfmt/src/container.rs declares 103 detected variants excluding None, asserted by detected_count_is_one_hundred_and_three. The same file declares 102 generic payload extractors and names LUKS1 as the one metadata-only generic boundary because its dedicated API requires a raw volume key, asserted by every_declared_format_names_its_extraction_boundary. The measured generic leg is 28 formats whose member bytes from a tracked input match what bsdtar 3.8.8, 7-Zip 26.02 or the format's own decompressor extracts from the same input (crates/disrobe-cli/tests/container_breadth.rs, crates/disrobe-cli/tests/golden/container_breadth.txt and container_breadth_reference.tsv). That roster also records 14 formats whose members no installed reference tool confirms and the committed PAR2 input as detect-only, leaving 59 generic extractors without a committed input. crates/disrobe-binfmt/tests/enigma.rs independently grades the Enigma Virtual Box 10.70 stored-member route with literal .enigma1 and .enigma2 section names against its upstream source file. crates/disrobe-binfmt/tests/real_luks1.rs separately grades the LUKS1 route by decrypting a tracked aes-cbc-plain fixture to byte-identical tracked VHD plaintext and entering the VHD extractor; crates/disrobe-cli/tests/luks1_extract.rs grades the file, stdin, keyless-wall, wrong-key, and unsupported-mode surfaces.
