# APK / DEX decompilation: disrobe vs JADX vs CFR

- id: `apk-jadx-cfr`
- ecosystem: android
- claim: On their respective committed EdgeCases inputs, real javac scores every emitted method by one source-only rule. The scorer compiles the complete recovered source set first. If a parse failure blocks attribution, it isolates the implicated balanced method, field-initializer, or type region under a 64-round ceiling and reruns javac. Methods in isolated method or type regions are unclean. Peer methods count only after javac reaches attribution. A leg publishes a lead only when both sides are certified.
- measured: Android DEX: `disrobe` 57 / 163 (35.0%) vs JADX not certified (295 methods emitted; the producer exited nonzero); JVM classfile: `disrobe` 181 / 181 (100.0%) vs CFR 152 / 166 (91.6%)
- oracle strength: recompile-only
- CI-attested: yes [CI]
- evidence basis: real javac (JDK), per-method recompile error-free against a STUBBED (empty) classpath so a wrong recovered signature cannot resolve against the original classes; one source-only scorer applies the same complete-compile, bounded region-isolation, and final diagnostic rule to every tool
- reproduce: `cargo run --locked -p disrobe-bench-head-to-head -- --check --only apk-jadx-cfr`
- gate source: evidence/results/measured/apk-jadx-cfr.json (regenerated by cargo run -p disrobe-bench-head-to-head)
- note: Needs javac, jadx, and cfr on PATH, with cfr.jar provisioned by evidence/competitors/install-linux.sh. Recompile-only: a clean method compiles under javac but is not asserted byte-equivalent. The DEX leg compares disrobe with JADX on EdgeCases.dex. The JAR leg compares disrobe with CFR on EdgeCases-baseline.jar because CFR cannot read DEX. The stronger JVM result remains the separately measured per-method recompile gate in the jvm-javac descriptor. Each tool's emitted count includes its nested, sibling, synthetic accessor, lambda, and bridge methods, so counts differ by design. Javac compiles the complete emitted source set first. When parsing prevents attribution, the scorer maps diagnostics to balanced source regions after lexically excluding comments, strings, chars, and text blocks. It replaces implicated method bodies with throwing stubs, field initializers with declarations, or malformed types with declaration-preserving named class shells, while preserving line count. It retries at most 64 times. Methods inside an isolated method or type region are unclean. Diagnostics after attribution determine the remaining method verdicts. An unmapped or over-budget parse failure publishes the emitted count without a rate and cannot produce a lead.
