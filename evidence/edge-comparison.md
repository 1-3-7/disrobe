# Comparison coverage

Each row pairs Disrobe's existing evidence with relevant tools and the shared-input benchmark needed to compare them. Results in the second column measure Disrobe alone.

The [head-to-head results](../benches/head-to-head/results.md) compare JADX, CFR, and APKLeaks on committed inputs with pinned versions. The table below identifies additional tools and input populations. Ghidra's packed-versus-rebuilt input measurements are linked from the [README](../README.md#give-ghidra-the-recovered-executable).
